# 🎮 About GRZ TOOL

**GRZ TOOL PUBG** is an open-source Windows utility designed to simplify PUBG Mobile emulator optimization.

Instead of manually changing multiple emulator and Windows settings, GRZ TOOL provides the most commonly used performance options from a single interface.

It is primarily optimized for **GameLoop** and provides presets and individual controls so users can choose which optimizations they want to apply.
